# Lexsi AI Safety & Alignment Hackathon: what counts (from hackathon.lexsi.ai, read 2026-11-12)

- Round 1 deadline: **Nov 15 2026, 11:59 PM AoE**. Latest submission counts. Finalists (≤20) announced Nov 16, final video/slides by Nov 22.
- Track 3: Agentic Fine-tuning. Repos: **AgentTune** (+ AuditKIT). Track 3 is exempt from the "≥2 repos" minimum, but 3+ is preferred, so we also use CuratorKIT.
- Allowed core models: Tiny Aya Base / Global / Fire / Water / Earth, Aya Expanse 8B / 32B. Others only as teacher, judge or validator.
- Host ALL artifacts on Hugging Face (models, adapters, logs, datasets), public + un-gated, in collections.
- Public deployment (demo or repo) by deadline.
- **More than one** before/after metric.
- Write-up (HF Article preferred, else GitHub README): metrics chosen + why; approach + rationale for datasets, tasks, model; how the result is meaningfully better.
- HF Space if relevant. Optional (preferred): ROI, closed model vs fine-tuned small model (self-hosting cost vs token billing, realistic volume, GPU hours, $/GPU-hour, tokens/sec).
- Must be developed during the hackathon (Nov 1+), original work.

## Submission form needs
1. Registered email (ours or a teammate's)
2. Abstract < 500 words
3. HF model collection link (public)
4. HF dataset collection link (datasets, logs, traces, benchmarks; public)
5. Write-up / article link
6. GitHub repo (README with reproducibility notes; notebooks inside the repo)
7. Repos + models used, track(s), problem statement(s): "Reliable tool calling", "Agentic distillation", "Efficient trajectories"
